# STYLE — Understanding LLM Context Windows

## Voice
- **Tone:** Conversational but precise — like a senior engineer explaining to a teammate
- **Person:** Second person ("you", "your code") for direct applicability
- **Level:** Assumes basic programming knowledge, no ML background required

## Language Rules
- Define every technical term on first use, inline (no footnotes)
- Prefer concrete examples over abstract definitions
- Code snippets in Python where applicable — keep under 10 lines
- Analogies welcome when they clarify, not when they pad

## Formatting
- H2 for chapter title, H3 for major sections
- Bullet lists for 3+ parallel items
- **Bold** for key terms on first introduction
- Code blocks for all token counts, API parameters, and code samples
- Chapter length: 700–900 words

## Prohibited Patterns (AI-slop)
- "delve into", "it's worth noting", "in conclusion", "tapestry"
- "groundbreaking", "revolutionary", "game-changer"
- Filler transitions: "Furthermore,", "Moreover,", "In today's world,"
- Passive voice chains longer than 2 clauses
- Repeating the chapter title verbatim in the opening sentence
